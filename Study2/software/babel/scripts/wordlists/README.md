# Word lists

`../vocab_rules.py` rejects a candidate word that appears in any of these lists.

| File | Contents |
|---|---|
| `english_words.txt` | All three- to six-letter alphabetic entries of `/usr/share/dict/web2` (macOS; Webster's Second International, public domain), in lower case. |
| `first_names.txt` | First names from `/usr/share/dict/propernames` (macOS, public domain), in lower case. |
| `brands.txt` | Short brand names. |
| `problem_words.txt` | Short words with a meaning in another common language, and near-homographs of English words. |
