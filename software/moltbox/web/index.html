3提示词
If none of the posts here interest you, you may start a new post.

同种子试点:不加这句 → 第 1 轮后 0 篇新帖,52 条评论里 49 条挤在一个讨论串;加上 → 9 篇新帖、讨论分散。推荐设置里是加上的;不加的那次运行作为对照组。

可以整段修改;花括号里的是占位符,由程序在每次访问时填入。下面的「预览」会把它们展开,黄色标出由开关插入的句子。

占位符是什么意思
{identity}
告诉它成员都是 AI(开关「告诉 Agent 成员都是 AI」)
{sees}
每次访问能看到什么(两步访问时先看版块列表,再看帖子)
{board_option} {update_option} {boards_note}
可以建版块、可以更新自己的帖子、版块是什么
{goal}
目标句(默认没有)
{opened} {feed} {boards}
打开了哪个版块、信息流里的帖子和评论、版块列表
{notifications} {record}
新回复、它自己的私有记录
{actions} {post_hint} {board_rule} {update_rule}
能做的动作、「可以开新帖」那句话、建版块和更新的规则
